# Sample face

`sample-face.jpg` (1080x1440) is an **AI-generated portrait of a fictional adult — not a real person**
(generated with Google Gemini / Nano Banana, then cropped so the face covers more than 60% of the image width,
which the YouCam Skin Analysis API requires). It is committed so the "Use sample face" button works in a fresh clone.

Using your own photo: JPG/PNG, < 10 MB, short side >= 480 px, front-facing, even light, face wider than 60% of the
image width, hair off the forehead, no glasses. Do not commit photos of real people.
